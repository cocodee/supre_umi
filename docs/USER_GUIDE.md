# UMI Studio 使用手册（最终用户）

> 一句话流程：**打开网页 → 三个状态变绿 → 填写任务名 → 按 `R` 开始 → 操作夹爪 → 按 `R` 结束 → 重复几次 → 点“完成并校验”。**

本手册面向日常采集人员，不需要了解程序细节。

---

## 1. 这套系统能做什么

UMI Studio 把三路数据同步记录下来，保存成 LeRobot 数据集：

- **相机**：夹爪上 USB 相机的画面
- **夹爪宽度**：AS5600 磁编码器测得的开口宽度
- **Tracker 位姿**：Vive Tracker 的 3D 位置和姿态

录完后可以在网页里回放视频、夹爪宽度曲线和位姿曲线，也能直接交给训练流程使用。

---

## 2. 开始前检查（约 30 秒）

| 检查项 | 确认内容 |
| --- | --- |
| 相机 | USB 相机已插好（镜头干净、对着操作区） |
| Tracker | Tracker 已开机；基站已通电；Tracker 在基站视野内 |
| 夹爪 | CH341 USB 转接器已插好，夹爪有电 |
| 电脑 | 已登录桌面（Steam 需要桌面会话） |

> 提示：Tracker 首次连接、SteamVR 刚启动时，状态可能要等 **15–30 秒**才变绿。

---

## 3. 启动系统

在目标机器上执行：

```bash
cd /home/zy/workspace/supre_umi/umi_devices
./start_web.sh
```

- **本机使用**：打开浏览器访问 <http://127.0.0.1:8770/>
- **远程使用**：先建 SSH 隧道，再在本地浏览器打开同一地址：

```bash
ssh -p 7022 -L 8770:127.0.0.1:8770 zy@23.254.219.130
```

启动时程序会自动拉起 **Steam 和 SteamVR**（无需手动开）。看到页面顶部三个状态灯都变绿即可开始。

## 4. 界面速览

```text
┌─────────────────────────────────────────────────────────────┐
│ 顶部：● 相机   ● Tracker   ● 夹爪      [↻ 重连]  [⚙ 设置]  │
├──────────────────────────────┬──────────────────────────────┤
│ 实时画面（相机预览）          │ 录制控制                      │
│ 夹爪宽度 / Tracker / 相机     │ 本数据集 Episodes             │
│                              │ 事件                          │
├──────────────────────────────┴──────────────────────────────┤
│ 数据集库（已录好的数据集）                                   │
└─────────────────────────────────────────────────────────────┘
```

- **顶部状态灯**：绿色=正常，红色/黄色=需要处理（见第 10 节）。
- **`↻` 重连**：设备没识别时点一下。
- **`⚙` 设置**：采集参数（第 7 节）。
- **右侧“事件”**：系统的提示和错误都会显示在这里。

## 5. 录制一段数据（核心步骤）

1. 在 **任务名称** 里填写任务，例如 `pick`（必填）。
2. **数据集名称** 可留空；留空会自动生成 `umi_日期_时间`。
   第一次录制时会自动创建数据集。
3. 点击 **开始录制**（或按键盘 `R`）→ 出现 **3 秒倒计时**（按 `Esc` 可取消）。
4. 倒计时结束后开始记录，操作夹爪完成任务。
5. 点击 **结束并保存**（或再按 `R`）→ 显示“正在保存…”，等它变回“开始录制”。
   保存时会把这段视频编码，**通常需要几秒，请稍等**。
6. 同一数据集可以继续录下一段：重复第 3–5 步。
7. 全部录完后，点右上角 **完成并校验** → 确认。
   校验通过后，数据集会出现在下方“数据集库”。

> 每一段“开始→结束”就是一个 **episode**。建议每个任务录 20–50 段，每段几秒到十几秒。

---

## 6. 录制中的质量提示

录制面板会显示：

| 指标 | 含义 | 正常情况 |
| --- | --- | --- |
| 帧数 | 本段已记录帧数 | 持续增长 |
| 目标帧率 | 每秒记录帧数 | 一般 30 |
| 相机缺失 | 相机帧没按时到达的比例 | 越低越好（应接近 0%） |
| 位姿无效 | Tracker 没拿到有效位姿的比例 | 越低越好（应接近 0%） |

- 三个质量条会按“最大缺失率”变色；变黄/红说明该路数据不稳定。
- 若在设置里开启了 **丢弃未通过 QC 的 episode**，超阈值的这段会被自动丢弃并提示。
- 位姿无效时，先检查 Tracker 是否被遮挡、是否在基站视野内。

## 7. 采集设置（点右上角 ⚙）

| 设置 | 默认 | 说明 / 建议 |
| --- | --- | --- |
| 输出目录 | `~/datasets` | 数据集都保存在这里，每个数据集一个子目录 |
| 相机设备 | 自动 | 一般不用改；多相机时在这里选择 |
| 分辨率 | 640×480 | 默认即可 |
| 目标帧率 | 30 | 一般 30；不要超过相机实际能力 |
| 数据集格式 | LeRobot v3.0 | 需要旧版兼容时选 **v2.1** |
| 启用 Tracker 位姿 | 开 | 不采位姿时可关闭 |
| 启用夹爪宽度 | 开 | 不采宽度时可关闭 |
| 夹爪标定文件 | 空 | 留空=理论值；可用“标定”向导生成后在此选择 |
| 最大样本时差 (s) | 0.05 | 三路时间对齐容差；一般不用改 |
| 最大缺失率 | 0.05 | 超过则质量条报警（开启丢弃时会被丢） |
| 最大位姿失效率 | 1.0 | 1.0=不限制；正式采集可收紧到 0.1 |
| 丢弃未通过 QC 的 episode | 关 | 想要“不合格自动丢弃”时打开 |
| 记录逐帧诊断 | 关 | 排查问题时打开，会在数据集 `qc/` 下写逐帧记录 |

> 数据集打开期间，帧率、格式和相机设置会锁定；完成并校验后可再改。

### 夹爪标定（网页向导）

夹爪宽度明显不准（例如完全夹紧时读数不是 0）时，用网页向导标定：

1. 打开控制台，在“夹爪宽度”卡片右上角点 **标定**。
2. 选择方式：
   - **快速两点（推荐先做）**：填入“全闭宽度”（通常 0 mm）和“全开宽度”（用卡尺量出的实际全开宽度，或按设计值 80 mm），点“开始标定”。
   - **多点分段**：填写已知宽度（如 0,20,40,60,80 mm）、重复趟数和每点采样数；更准，并能补偿张开/夹紧的迟滞。
3. 按提示把夹爪放到目标宽度并**保持不动**，点“记录该点”：
   - 快速两点：先完全夹紧记录“全闭”，再完全张开记录“全开”。
   - 多点分段：按“张开/夹紧 + 宽度”的提示逐点记录；放错可点“撤销上一点”。
4. 全部记录后点 **拟合标定**，查看训练/留出误差和线性基线对比。
5. 点 **应用并保存**。夹爪会自动重连，宽度立即按新标定显示，卡片上的“理论值”会变成标定文件名。

注意：

- 请用卡尺量出真实的全开/全闭宽度再填，不要假定 80 mm 就是实际行程。
- 记录时夹爪要静止；系统会平均约 0.6 秒读数以抑制 50 Hz 抖动。
- 标定文件保存在 `umi_devices/gripper_calib_*.json`，也可在“设置 → 夹爪标定文件”里手动选择。
- 数据集打开或录制过程中不能标定，请先完成并校验。

## 8. 数据保存在哪

默认在 `~/datasets/<数据集名称>/`，主要结构：

```text
meta/      数据集说明、任务、统计
data/      每帧的夹爪宽度、位姿等数值（parquet）
videos/    相机视频（mp4）
qc/        质量检查记录
```

- 格式选 **v3.0** 时为多 episode 共用的 `file-xxx` 文件；选 **v2.1** 时每个 episode 一个文件。
- 原始数据会保留，方便以后重新标定或转换格式。

---

## 9. 回放与检查

1. 在“数据集库”点击一个数据集。
2. 点 **数据浏览**：可看视频、夹爪宽度曲线、Tracker 位置/姿态曲线。
3. 点 **校验数据集**：检查文件是否完整。

浏览时快捷键：`空格` 播放/暂停，`←`/`→` 逐帧，`Esc` 关闭。

## 10. 常见问题

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 顶部“相机”红 / 录制按钮灰色 | 相机没连上或被占用 | 点 `↻` 重连；检查 USB；关闭其它用相机的程序。节点号变化时系统会自动切换，无需手动改 |
| 顶部“Tracker”红 | Steam/SteamVR 未就绪、Tracker 没开、基站没电或超出视野 | 等 15–30 秒；确认 Tracker 开机、基站在视野内；点 `↻` 重连 |
| “夹爪”红 | CH341 没插好或权限问题 | 重新插 CH341；点 `↻`；仍不行联系工程人员 |
| 顶部显示“SteamVR 正在启动” | 首次启动较慢 | 等待，事件区会提示“Tracker 已自动重连” |
| 录制按钮显示“正在保存…” | 正在编码视频 | 等它结束，不要关页面 |
| 提示“episode 未通过 QC，已丢弃” | 打开了丢弃选项且数据不达标 | 检查相机/Tracker/夹爪状态后重录 |
| 页面打不开 / 端口被占用 | 已有一个采集服务在运行 | 先关掉旧的服务（或重启机器）再运行 `./start_web.sh` |
| 位姿经常无效 | Tracker 被手/线缆遮挡，或离基站太远 | 调整基站位姿和操作范围 |

## 11. 使用注意事项

- **基站视野**：单基站方案要保证 Tracker 在整个动作过程中尽量不被手、夹爪和线缆挡住。
- **线缆应力**：相机和 CH341 的线要留出余量，避免拉扯和缠绕。
- **夹爪宽度**：传感器静止时会有约 50 Hz 的读数摆动，程序已做平滑；若宽度明显不准，需要工程人员重新标定。
- **不要中途拔设备**：录制过程中拔相机/CH341 会导致该段数据不完整。
- **保存需要时间**：每段结束后等“已保存”提示再开始下一段。
- **先 Steam 后 SteamVR**：系统已自动处理；如手动启动，务必先开 Steam 客户端，再开 SteamVR。
